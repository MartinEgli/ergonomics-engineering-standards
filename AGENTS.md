# Agent Guidance

## Required Reading

1. `README.md`
2. `standards/engineering-standards-ergonomics.md`
3. `CHANGELOG.md` when normative behavior changes

## Rules

1. Keep this repository technology-independent.
2. Do not copy copyrighted ISO publication text.
3. Distinguish derived engineering guidance from certified ISO conformity.
4. Write observable and reviewable requirements using `Must`, `Should`,
   `Could`, and `Must Not`.
5. Put framework-specific adaptations in the consuming technology standard.
6. Document consumer impact for every stricter normative change.
